# Kakeibo API Playground

AdonisJS (TypeScript) を使った **学習用の家計簿アプリ**。  
REST API で構築し、TypeScript を用いたバックエンド開発を試すためのリポジトリです。

## Using Cursor

This project utilizes Cursor for enhanced code assistance and project management. Cursor helps in maintaining code quality and provides intelligent suggestions during development.
